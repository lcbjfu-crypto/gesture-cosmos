# 星球粒子手势宇宙

这是一个全屏黑色科技风的浏览器互动作品。圣诞树由不同颜色、大小、带光晕或星环的星球粒子组成。

## 运行

双击 `启动动画.bat`。启动器会先检查并启动本地服务，确认页面就绪后再打开浏览器。进入页面后点击“启动摄像头手势识别”，并允许摄像头权限。首次启动需要联网加载 MediaPipe Hands 模型。

## 可见验证项

- 摄像头：右上角显示实时摄像头画面和 FPS。
- 手部骨架：检测到手时叠加 21 个关键点和连接线。
- 识别状态：显示当前手势、伸展/弯曲手指数和捏合距离。
- 粒子响应：手掌位置显示 `HAND FIELD` 圆环，附近星球会被推开。

## 手势

- 张开手掌：星球粒子展开到宇宙空间。
- 握拳：星球重新聚合成圣诞树。
- 拇指与食指捏合：在手部位置触发一次星光爆炸。
- 移动手掌：移动排斥力场并推开附近星球。

摄像头必须通过 localhost 或 HTTPS 打开；直接双击 `index.html` 可能无法获取权限。
